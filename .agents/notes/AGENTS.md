# AGENTS.md — Agent Notes

Agent Notes 是由 agent 编写的 RFC：持久化的提案和决策记录，保留理由、替代方案、后果和必需验证。
遵循 [Agent Note 规范](README.md)。

**每个新 Agent Note 触发取代检查。** 搜索活跃目录树中覆盖相同决策或机制的旧 note，
将任何完全或部分取代分类，并在同一个 PR 中归档每个符合条件的已实现三元组。
保持部分取代的 note 活跃并交叉链接。

[`archived/`](archived/AGENTS.md) 下的文件是冻结的历史快照：绝不编辑它们或将它们视为当前权威。
