## 保持已实现 Agent Note 与实际发布同步

当路径、符号、默认值和机制在代码变更中被修改时，在同一变更中保持它们同步。
就地重写过时的事实；不要追加变更历史。

当已发布的 note 不太可能指导未来工作时，通过归档工作流归档其完整三元组，而不是继续维护它。

### 这不是重写*决策*的许可

就地更新事实实现。逆转决策或其理由需要新的 Agent Note 和交叉链接；
完全被取代的旧 note 只能通过[Agent Note 规则](../README.md)中的合并规则删除。
