# AGENTS.md — Archived Agent Notes

归档的 Agent Note 是冻结的历史快照。

- 只有已实现（`implemented`）的 note 可以进入归档。
- 归档路径编码为 `archived/{class}/yyyy-mm-dd-topic-title.md`。
- 归档时在 `Status: implemented` 行正下方插入 `Archived: YYYY-MM-DD` 行。
- 一旦封存，永久冻结：绝不编辑、翻译、重新格式化、更新、移动或删除。
- 不要将归档 note 视为当前行为的权威。
- 文档门控跳过归档来源，包括其出站链接。
- 活跃文本在有意引用历史时仍可链接到归档 note。
